# Team Manager (básquet)

Gestión de equipo estilo Football Manager para cualquier categoría o torneo:
tabla de posiciones, plantel y planilla de partido, pizarra, tabla de profundidad,
scouting de rivales y control de estímulos semanales.

## Cómo se usa
1. Abrí `index.html` (o la página de GitHub Pages).
2. Subí las planillas de estadísticas de CABB (.xlsx sueltas o un .zip).
3. Elegí tu equipo. Listo.

Podés cargar varios equipos/torneos (botón **Nuevo**) y cambiar desde el selector del encabezado.
Los datos se guardan en el navegador de cada dispositivo; usá **Respaldo** para pasarlos a otro.
